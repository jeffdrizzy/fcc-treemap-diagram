# Treemap Diagram — Movie Sales

freeCodeCamp Data Visualization certification project.

## What it shows

Top 100 highest grossing movies grouped by genre, from the official
freeCodeCamp dataset:
`https://cdn.freecodecamp.org/testable-projects-fcc/data/tree_map/movie-data.json`

## How to run

Open `index.html` in a browser (serve the folder with any static server,
e.g. `python3 -m http.server`), or host it live. D3.js is loaded from a CDN.

## Tests

The freeCodeCamp test bundle (`bundle.js`, included at the end of
`<body>`) runs the Treemap Diagram test suite against this page.
